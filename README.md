# "SMK Open" for Vistava

View the collection of the National Gallery of Denmark with [Vistava](https://vistava.net).

## About

The National Gallery of Denmark digitized its enormous collection of art and made it available freely to the public through the [SMK Open project](https://www.smk.dk/en/article/smk-open/). This extension allows you to access this collection of art directly from within the Vistava application.

[![Developed by a Human, Not by AI](assets/badge.png "Developed by a Human, Not by AI")](https://notbyai.fyi)

## How to install

Assuming you have [Vistava](https://vistava.net) set up already, installing the extension can be done in a few simple steps:

1. Download the extension package from the [Releases tab](https://github.com/bauermaximilian/SMK-Vistava/releases)
2. Open Vistava and click on the "Extensions" button (with the "puzzle piece" symbol) in the title bar, then on "Install extension..." and confirm the security warning
3. In the dialog, select the extension package file you downloaded earlier and confirm
4. Optional: To enable the search option or shortcuts to specific artists, click "Yes" in the dialog and enable (or add) specific shortcuts in the configuration file
5. Restart Vistava

The extension can now be accessed through the extension menu under the "SMK" option.

## Troubleshooting

If the extension does not appear after installing, make sure the configuration file is valid JSON - this can be done by validating the file content with a JSON validator. To reset the configuration file to its initial state, just reinstall the extension and don't open/edit the configuration file afterwards before restarting Vistava. For more information, consult the official [Vistava documentation](https://vistava.net/docs.html#/4-advanced?id=installing-extensions).
